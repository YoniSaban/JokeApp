# Milestone 6: הקהילה מדרגת

## המטרה
"אהבתי" ו"לא אהבתי" במקום "צחקתי", קול אחד לכל משתמש לכל בדיחה, לשונית קהילה ולשונית אהבתי.

## מה נבנה
| קובץ | מה יש בו |
|---|---|
| db/create_votes.sql | ‏public.votes עם מפתח ראשי (user_id, joke_id), ‏check של 1 או 1-, אינדקס על joke_id, ‏RLS בלי policy והרשאות ל-service_role בלבד. הפונקציות cast_vote (plpgsql) ו-joke_feed (sql, stable), שתיהן security invoker עם `search_path = ''`, ו-execute רק ל-service_role |
| api/vote.js | ‏POST עם טוקן בלבד. ‏`{ id, value }`: ‏id חייב להיות uuid, ‏value המספר 1, 1- או 0 בדיוק. המצביע מהטוקן בלבד. בדיחה שלא קיימת: 404. מחזירה `{ likes, dislikes, my_vote }` |
| api/feed.js | ‏GET עם mode של new, ‏top או liked. ‏20, ‏10 ו-50 שורות. ‏liked בלי טוקן: 401. טוקן לא מוכר: 401. מחזירה `{ jokes }`, עם רשימה סגורה של שדות, בלי user_id |
| api/laugh.js, api/top.js | נמחקו |
| index.html | שלוש לשוניות בתחתית (‎#joke, ‎#community, ‎#liked), רכיב הצבעה אחד מ-template, קהילה עם "חדשות" ו"הכי מצחיקות" ומספר דירוג, אהבתי עם מסך נעול לאורח, וקישור לקהילה מתחת לבדיחה |
| sw.js | ‏`joke-v4` |

## החלטות
- ‏cast_vote בודקת קודם שהבדיחה קיימת, וזורקת P0002. ‏api/vote.js מתרגמת את P0002, וגם 23503 (בדיחה שנמחקה באמצע), ל-404.
- ‏my_vote הוא 0 כשאין הצבעה, ב-cast_vote וב-joke_feed, כדי שהדף לא יצטרך לטפל ב-null.
- ‏feed.js: כש-Supabase Auth לא זמין, ‏new ו-top חוזרות כמו לאורח, ו-liked מחזירה 503.
- אורח שלוחץ על הצבעה: ההצבעה נשמרת בזיכרון, וחלון הכניסה נפתח עם "כדי לדרג בדיחות צריך חשבון". כשהחלון נסגר, אם יש טוקן ההצבעה נשלחת, ואם לא היא נשכחת.
- רשימה שנטענת מחכה קודם להצבעות שעוד בדרך, כדי שתשובה ישנה לא תדרוס הצבעה חדשה. רק התשובה האחרונה של כל לשונית נכנסת למסך.
- ההצבעה מתעדכנת בכל המקומות שבהם הבדיחה מופיעה. ביטול "אהבתי" בלשונית אהבתי מוציא את הכרטיס.
- כניסה או יציאה (שינוי משתמש, לא רענון טוקן): הרשימה הפתוחה נטענת מחדש. ביציאה, הסימון מתחת לבדיחה בלשונית בדיחה נמחק.
- הודעת שגיאה של הצבעה מופיעה בפס קצר מעל הלשוניות, ונעלמת אחרי 3.5 שניות.
- כל טקסט מהשרת נכנס עם textContent.
